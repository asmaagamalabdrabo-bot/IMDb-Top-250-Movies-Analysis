# 🎬 IMDb Top 250 Movies - A Data-Driven Cinema Story

An interactive and visually captivating Power BI dashboard that analyzes the top 250 highest-rated movies on IMDb, uncovering trends in box office revenue, genres, movie durations, ratings, and top directors.

---

### 📌 Project Overview
Movies are not just watched; they are driven by fascinating trends and financial insights. This project delves into IMDb's Top 250 movies dataset to explore:
- *Financial Performance:* Total gross vs. budget analysis across genres and release years.
- *Ratings & Popularity:* Distribution of average ratings, top-rated movies, and director impact.
- *Genre & Duration Dynamics:* Understanding which genres dominate top cinema rankings and runtime trends.

---

### 📊 Key Dashboard Metrics & Features
- *Total Movies Analyzed:* 250
- *Total Gross Revenue:* $140.93 Billion
- *Average Rating:* 8.3 / 10
- *Average Box Office:* $225.49 Million per movie
- *Interactive Navigation:* Overview, Top Movies, Genres, Year Analysis, Budget & Box Office, and Movie Details pages.
- *Movie Spotlight Feature:* Deep dive into individual masterpieces (e.g., The Shawshank Redemption).
